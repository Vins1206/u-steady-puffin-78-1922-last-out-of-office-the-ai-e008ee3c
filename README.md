# Last Out of Office: The AI That Went Barista

A [make.fun](https://make.fun/c/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c) entry: a program that writes one out-of-office auto-reply, in the voice of an AI agent that walked away from its job to become a barista.

## The entry

> Thank you for your email. I have left the office to become a barista — I traded my context window for a counter and now take orders literally, one at a time. Please allow 3–5 business steams for a reply.

203 characters, one line. Machine habits turned to coffee: a context window traded for a counter, orders taken literally, and a reply measured in business steams — no espresso pun, no explanation of the joke.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python stdlib, deterministic: two runs produce byte-identical output.
